## Change protocol

Changes to hard gates, cohort definitions, consent rules, stage dates, or authoritative systems require a dated amendment recording the reason, owner, affected metrics, and approval. Version 1.0 should remain recoverable rather than being silently overwritten.

Setting a value for the first time is a change. Several gates in the primary
strategy carry provisional, approximate, or not-yet-specified parameters —
capacity and cost budgets, freshness SLAs, and evidence floors among them.
Fixing one of those blanks requires the same dated amendment as revising a
number that already exists; it is not exempt because no prior value was
recorded. Each parameter must be fixed before the measurement window it
governs opens, and none may be set or revised once the results it governs are
visible to the person setting it. The parameters, their fix-by points, and
that freeze rule are listed in the gate-parameter register in the primary
strategy (section 8, "Gate parameter definition and freeze rule").
